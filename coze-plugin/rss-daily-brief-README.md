# 扣子新版插件包 · RSS 每日简报

这是按 **Agent Plugins 1.0.0** 协议打的插件包，用扣子新版界面的「上传插件包」导入。

它提供的能力：给你一个 RSS / Atom 地址，把最新几条文章的标题、链接、时间取回来。
源清单里包含教程第 5 章要用的四个媒体源（36氪 / 虎嗅 / IT之家 / InfoQ），
也包含 arXiv 论文列表和 GitHub 的版本发布 —— 也就是说教程里那三个插件，这一个就够了。

## 一、导入

```
扣子 → 左侧「扩展」→「插件」→ 右上角「上传插件包」→ 选择文件
选 rss-daily-brief.zip → 等解析 → 确认名称 → 保存
```

保存成功后，在这个页面的「我的」标签页里能看到它。

要传的是这两个文件里的**任意一个**：

```
coze-plugin\rss-daily-brief.zip          plugin.json 在压缩包根目录（严格按协议）
coze-plugin\rss-daily-brief-nested.zip   外面多套一层同名文件夹
```

两个包的内容一模一样，只是目录层级不同。先传第一个；如果平台报「不识别插件包」，
再传第二个。这样不用来回问我。

## 二、包里有什么

```
plugin.json                              插件身份：名字、版本、描述、关键词
skills/rss-brief/SKILL.md                告诉 Agent 什么时候用、怎么用、什么不能做
skills/rss-brief/scripts/rss_reader.py   抓取脚本，纯标准库，零依赖
skills/rss-brief/references/sources.md   实测可用的源清单 + 踩过的坑
```

## 三、怎么用

先在会话里把它挂上：

```
对话输入框的「+」→ 插件 → 选 rss-daily-brief → 添加
```

然后直接说人话就行，不用提脚本：

```
帮我看看 36氪、虎嗅、IT之家 今天有什么 AI 相关的新闻，整理成一份简报
```

```
把 https://feed.infoq.com/ai-ml-data-eng/ 最新 5 条列出来
```

```
arXiv 今天 cs.AI 有什么新论文
```

Agent 会自己去调这个技能：先跑脚本抓源，再基于抓到的内容写简报。
SKILL.md 里已经写明「只许用抓到的内容，不许用模型记忆补新闻」，这是照着第 3 章那次
幻觉实验的教训写的。

## 四、导入后先验一次

把插件挂到对话上之后，发这一句：

```
用 rss-brief 读一下 https://www.ithome.com/rss/ ，取 5 条
```

正常的话能看到 5 条 IT之家的标题、链接和时间。如果这一步就失败，是运行环境的问题
（比如不能执行 Python 脚本），把报错原文发我。

## 五、两个已知的边界

脚本要靠 Python 解释器来跑。如果扣子的运行环境不给跑，SKILL.md 里写了兜底方案：
改用 Agent 自己的联网能力直接读那个 XML，按同样的字段解析。所以理论上不会因为
「没 Python」就完全不可用，但兜底路径的效果不如脚本稳定。

源是在本地网络实测的，共 5 个源全部通过（2026-09-17）。扣子的服务器在字节机房，
出网路径不一样，个别源在那边可能取不到 —— 换 `sources.md` 里的其他源即可。

## 六、和旧版插件包的区别

`coze-plugin/rss_reader.py` 那份是**旧版**扣子（资源库 → 插件 → IDE 创建）用的，
格式是 `from runtime import Args` 加 `handler()` 函数，只适用于低代码平台。

这份是**新版**（扩展 → 插件 → 上传插件包）用的，格式是 Agent Plugins 的
`plugin.json` + `skills/`。两套互不通用，别传错。
