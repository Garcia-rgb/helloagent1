## 这一章的骨架：一条「问题驱动」的链

全章的主线一句话：**每一个新范式的出现，都是为了解决上一代范式的核心痛点，同时又埋下新的痛点。**

| 阶段 | 范式 | 解决了什么 | 留下什么新问题 |
|---|---|---|---|
| 2.1 | 符号主义 / 专家系统 | 逻辑推理可以形式化，能在垂直领域超过人类（MYCIN） | 知识获取瓶颈、常识缺失、框架问题、脆弱 |
| 2.2 | 规则驱动对话（ELIZA） | 不用理解内容也能营造"智能"假象 | 无语义、无状态、规则爆炸 |

| 2.4.3 | 预训练 + 微调 | 知识不再靠人编码，直接从海量文本学到 | 只是"模型"，还不是"智能体" |

## 2.1 符号主义：四个关键点

- **物理符号系统假说（PSSH，1976，纽厄尔 + 西蒙）**：充分性论断（物理符号系统足以产生通用智能）+ 必要性论断（能产生通用智能的必然是这个东西）。一句话：**智能的本质就是符号的计算与处理。**
- **专家系统**：知识库（IF-THEN 产生式规则）+ 推理机（正向链 = 数据驱动；反向链 = 目标驱动）。知识与推理分离是符号主义的标志特征。
- **MYCIN**（斯坦福，1970s）：约 600 条医学规则，反向链工作，创新点是**置信因子 CF**（-1 到 1）处理不确定性。诊断水平达到人类专家。
- **SHRDLU**（Winograd，1968-70）：积木世界里的自然语言交互。历史地位在于第一次把语言解析、规划、记忆集成在一个系统里，**"感知-思考-行动"闭环设计的源头**。

符号主义的两个根本难题：

- **知识获取瓶颈**：专家知识是内隐的，手工编码成 IF-THEN 成本高、不可规模化（Cyc 项目几十年的教训）
- **框架问题 + 脆弱性**：动作执行后哪些状态没变难以高效判断；遇到规则外的微小变化就完全失灵

## 2.2 ELIZA 与规则驱动的极限

ELIZA（魏泽鲍姆，1966）不是单一程序，是**框架 + 脚本**。最出名的脚本是 DOCTOR（模仿罗杰斯学派心理治疗师）。

它从不正面回答问题，只做四件事：关键词识别与排序 → 分解规则（带 `*` 通配）→ 重组规则（随机选一条）→ 代词转换。

### 实跑验证到的事实（本次实测）

| 项 | 实测结果 |
|---|---|
| 规则条数 | 7 |
| 代词映射 | 12 项 |
| 优先级机制 | 就是字典的插入顺序，`re.search` 从上往下试，**第一条命中的就用** |
| `I am not happy` | 命中 `I am (.*)`，捕获 `'not happy'` → 回应 `How do you feel about being not happy?`（语义崩了） |
| `I am Feeling SAD` | 捕获组 `'Feeling SAD'` → `swap_pronouns` 里 `.lower()` 后变成 `'feeling sad'`，**大小写全丢** |
| `mother is worried` | **不命中** `.* mother .*`（该模式要求 mother 前后都有空格）→ 掉到兜底 `.*` |
| `My mother is worried` | 命中 —— 同样的意思，换个开头结果完全不同 |
| `I am worried about my father` | 命中 `I am (.*)` 而不是 father 规则，因为 `I am` 在字典里排前面 |
| `I need`（无后续） | **不命中** `I need (.*)`（模式里 `I need ` 带尾空格）→ 掉到兜底 |
| `Why don't you help me?` | 捕获 `'help me'` → 代词转换后 `'help you'` → `Do you really want me to help you?` |
| 末尾兜底 `return` | **死代码**。`r'.*'` 排在字典最后且能匹配任何输入（含空串），循环必然在那里 return |
| 回应内容 | 同输入每次不同 —— `random.choice` 从候选模板里抽 |

**教程示例对话与实跑不一致是正常的**：文档里那四句是某一次抽样的结果，不是固定答案。

### 三条根本局限（对应教材 2.2 节末尾）

1. **缺乏语义理解**：不理解否定词，`not happy` 和 `happy` 对它没区别
2. **无上下文记忆**：全局没有任何地方保存历史，每轮只看当前单句
3. **规则扩展性问题**：规则间冲突与优先级管理会迅速失控

ELIZA 效应（用户以为它懂自己）= 巧妙的对话策略（被动提问者 + 开放式模板）+ 人类的情感投射。

## 2.3 明斯基的心智社会

核心不是"更聪明的单一系统"，而是**大量"无心"的简单智能体协作，涌现出复杂行为**。

- **智能体（这本书里的定义）**：一个极简单的专门化心智过程，自身"无心"，如 `LINE-FINDER`、`GRASP`
- **机构（Agency）**：一组协同工作的智能体，完成更复杂的任务，如 `BUILD`
- **涌现（Emergence）**：搭积木塔的例子 —— 没有任何一个组件拥有全局规划，`GRASP` 不知道什么是塔，`BUILDER` 不知道怎么控制手臂，但行为整体涌现出来了

对多智能体系统（MAS）的三点启发：去中心化控制、涌现式计算（蚁群 / 粒子群）、智能体的社会性（通信语言 ACL、契约网、协商、信任模型）。

## 2.4 学习范式：从"设计智能"到"学习智能"

这一段的转折问句值得记住：**如果智能无法被完全设计，那它能否被学习出来？**

- **联结主义**（1980s 复兴）：知识以连接权重分布式存储；简单处理单元；通过反向传播调整权重。智能力量来自学习过程，不来自设计者编写的程序。
- **强化学习**：五要素 Agent / Environment / State / Action / Reward；策略 π 是从状态到行动的映射；学习目标是**累积奖励（回报）**而不是即时奖励 —— 所以需要"远见"（围棋弃子）。
- **预训练 + 微调**：自监督学习（最常见目标是"预测下一个词"）→ 通用基础模型 → 少量标注数据微调适配下游任务。**这一步直接解决了符号主义的知识获取瓶颈** —— 知识不再是编码进去的，是从数据里学出来的。
- **涌现能力**：规模跨过阈值后出现未被直接训练的能力，主要是**上下文学习（In-context Learning，Few-shot / Zero-shot）**和**思维链（CoT）**。

### LLM 智能体的核心循环（图 2.10）

```
感知 Perception → 思考 Thought → 行动 Action → 观察 Observation → （回到感知，并更新记忆）
```

- **感知**：从环境接收原始输入，形成 Observation
- **思考**：规划模块做反思与自我批判，把宏观目标拆成可执行步骤；LLM 与记忆模块交互后决定下一步，产物是**工具调用**
- **行动**：执行模块解析工具调用指令，从工具箱里选并执行
- **观察**：工具结果 + 新的环境状态构成新的 Observation，同时更新记忆，进入下一轮
